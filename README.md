# Code Refactoring Project

## Description

This project demonstrates how an existing Python script can be improved through refactoring, clearer naming, documentation, and more readable Python code while preserving the program's original functionality.

## Files

- undocumented_script.py - The refactored Python program.
- CODE_REVIEW.md - Initial observations and the final code review.
- DECISIONS.md - Explanation of the refactoring and design decisions.

## How to Run

Make sure Python is installed, then open a terminal in the project folder and run:

    python undocumented_script.py

## Expected Output

    Processed Numbers: [3, 4, 9, 8, 15, 12, 21]
    Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY
